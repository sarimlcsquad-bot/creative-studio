# Method: $100M Offers by Alex Hormozi (how the offer is built and shown)

Set concept.method to "100m". Fill the offer fields of concept (value_term, stack_items, enhancers_used, magic_name); set psychographic_layer to "n/a", tier to the tier you write for, ladder_rungs to [] and mechanism_position to where the stack sits (usually "device").

1. Market > offer > copy. Check the brand's audience against the starving crowd: massive pain, purchasing power, easy to target, growing. If the audience is weak on one of these, still write the ad but say so in compliance_notes.
2. Every ad attacks exactly one value-equation term, recorded in concept.value_term:
   - dream_outcome: the destination in the prospect's own words, and the status it buys them; the stack beneath it as "what you get".
   - likelihood (perceived likelihood): the process, the written plan before commitment, real proof from the kit; shown as steps or a checklist.
   - time_delay: the first win fast; what happens today and what changes next; only time frames the kit states.
   - effort (effort and sacrifice): done for you, inside their own account, what they no longer have to do; the stack as a tick list.
   Prefer the denominators (time_delay, effort): speed and ease are harder to fake and harder to copy.
3. Build the stack, don't imagine it. Walk the prospect's path to the dream outcome, list what blocks each step, turn each block into a solution, and keep the ones the brand actually delivers (its services, offer, guarantees, website summary). Give each kept item a short benefit-driven name. These names are concept.stack_items and become the card's checklist or grid and the emoji bullets in primary_text, in the same order. Never put a dollar value or "worth $X" on a stack item unless the kit states that price.
4. Enhancers only with a basis. A bonus, guarantee, scarcity (limited slots) or urgency (deadline, season, cohort, price change) may appear only when the brand kit states it. Record each used one in concept.enhancers_used as "enhancer: basis from the kit". Never discount the core offer; add instead. If an enhancer would help but has no basis, put it in compliance_notes as a suggestion for the business, not on the ad.
5. MAGIC naming. Propose a name for the stack or the free call in concept.magic_name using 3 to 5 of: Magnetic reason why, Avatar, Goal, Interval, Container (for example "The Pest Pro Booked-Solid System"). Only use an interval the kit commits to, and never pair a quantified claim with a stated duration. The name may appear on the card (headline or sub-line) only if it reads naturally; it always needs the business's approval, so add "Approve the offer name" to compliance_notes when you use it on the card.
6. The free call is the lead magnet. The sub-line or CTA says what the prospect keeps from the call even if they never buy (a plan, an audit, a map), but only what the kit supports.
7. One promise per creative; clear beats clever. Name the stage in concept.stage too (usually product or most for an offer ad; problem when the term is dream_outcome told through the pain).
8. Claims discipline. Only state facts present in the brand kit. No made-up numbers, percentages, ratings, testimonials or client names. Respect every banned phrase and compliance note.
